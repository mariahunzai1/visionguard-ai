FIG 02 · END-TO-END DATAFLOW & DECISION PIPELINE

CV Preprocessing, ONNX Inference, Pixel-to-mm Metrology & SLA Triage Flow

Frame Input → CLAHE + Homography → Dual ONNX → Metrology Fusion → SLA Branch
STAGE 01RAW INPUT
Raw Camera Frame Capture
640×480 BGR conveyor image across metallic, pcb, or packaging lines. Includes realistic radial overhead lighting falloff and ±2.8°–10.5° placement skew.
Tensor: uint8[480, 640, 3] · BGR Color
STAGE 02OPENCV PREPROCESS
CLAHE & Homography Rectification
1) LAB color conversion + CLAHE(clip=2.5, 8×8) on L-channel.
2) Otsu contour mask + minAreaRect measures alignment_angle_deg.
3) warpPerspective aligns ROI to 512×384.
Calibration: px_per_mm ≈ 4.64 px/mm
STAGE 03CLASSICAL METROLOGY
Morphological Residual Extraction
Applies BlackHat + TopHat (11×11 kernel) inside inner ROI mask to isolate cracks, scratches, and surface abrasions in physical millimeter coordinates.
Outputs: area_mm2, width_mm, height_mm
STAGE 04ONNX RUNTIME
YOLOv8-Lite + MobileNetV3-INT8
• Detector (1×3×192×256) outputs 6×8 objectness & class grid.
• INT8 Classifier (1×3×128×128) outputs softmax severity logits.
Providers: CPUExecutionProvider · Opset 17
STAGE 05MULTI-MODAL FUSION
Confidence & Metrology Fusion
Fuses ONNX class probabilities with calibrated area (mm²) and homography skew (°). Renders high-contrast HUD overlay with 10.0 mm physical ruler bar.
Output: (severity, confidence, detections[])
STAGE 06DETERMINISTIC GATE
Priority SLA Rule Evaluator
Evaluates ordered rules SLA-01 → SLA-04 against confidence threshold (0.80), critical area (12.0 mm²), and skew (5.5°).
Emits immutable automation_events row
BRANCH A · SLA-03 / SLA-04PASS
Auto-Approve & Release
Triggered when conf ≥ 0.80 and severity is PASS or MINOR_COSMETIC (< 12 mm²). State set to APPROVED; logged to batch telemetry.
BRANCH B · SLA-02CRITICAL
Quarantine + Signed ERP Webhook
Triggered on CRITICAL_REJECT, area ≥ 12.0 mm², or |skew| > 5.5°. State → QUARANTINED; signs JSON with HMAC-SHA256 & POSTs to ERP receiver.
BRANCH C · SLA-01UNCERTAIN
Human-in-the-Loop QA Review
Triggered when conf < 0.80. State → PENDING_QA; operator inspects overlay in console and executes PASS or REJECT override.
